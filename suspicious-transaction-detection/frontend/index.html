      PROJECT INFORMATION

      About FraudShield

      A machine learning demonstration for transaction monitoring and risk review.

      How it works

      Transactions are cleaned and converted into features before the active model scores them. Labeled training data selects a supervised classifier by holdout F1; unlabeled training data uses Isolation Forest. The dashboard applies configured thresholds to show low, medium, or high risk.

      Interpret results carefully

      The bundled labels are synthetic examples. Model results and risk scores are not evidence of confirmed fraud. Review flagged transactions with context and use representative, confirmed outcomes before considering real deployments.

      Supported transaction data

      CSV imports must contain the transaction fields listed on the Batch Analysis page. Missing numeric values can be imputed by the ML service; malformed rows are rejected during import.
